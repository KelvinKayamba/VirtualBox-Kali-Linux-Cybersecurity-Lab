# VirtualBox-Kali-Linux-Cybersecurity-Lab

# Overview

This project involved setting up a virtual cybersecurity testing environment using Oracle VirtualBox and Kali Linux as part of the NetworkWalks Academy Week 1 Cybersecurity Project.

The objective was to create a dedicated environment for cybersecurity and ethical hacking practice, configure virtual networking, and prepare Kali Linux for practical security exercises.

# 1. VirtualBox Configuration

Installed and configured Oracle VirtualBox to create a virtualised cybersecurity lab environment.

# Configuration tasks:

- Installed Oracle VirtualBox.

- Created a custom NAT Network using the 10.0.0.0/24 subnet.

- Configured virtual machine networking.

- Enabled clipboard and drag-and-drop integration.

- Configured shared folder functionality.

- Prepared the environment for Kali Linux installation.

**Screenshot:** https://github.com/KelvinKayamba/VirtualBox-Kali-Linux-Cybersecurity-Lab/blob/main/Virtualbox%20Configuration.png


# 2. Kali Linux Installation and Configuration

Downloaded and imported Kali Linux into VirtualBox, then configured the virtual machine according to the project requirements.

# Configuration tasks:

- Installed and configured Kali Linux as a virtual machine.

- Connected Kali Linux to the custom NAT Network.

- Configured a static IP address of 10.0.0.2/24.

- Configured shared folders using the host's /downloads folder.

- Enabled clipboard and drag-and-drop functionality.

- Configured internet connectivity.

- Practised Linux network configuration and troubleshooting.

- Created a virtual machine snapshot.
